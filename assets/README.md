# Artwork and provenance

Game art has a true orthographic overhead camera. Simulation geometry stays in terrain/boat data; decorative sprites, clipping paths, noise and rock/canopy details never define collision, depth or habitat.

## Canonical asset layout

The designer authorized removal of exact duplicates after verification. `public/assets/` holds the canonical game artwork, including unchanged original PNGs and editable SVGs. `assets/` holds unique source/reference artwork, provenance and authoring recipes. See [layout and cleanup record](../docs/ASSET_LAYOUT.md) and [original fingerprints / former paths](asset-integrity.json).

## Generated workboat

Built-in **imagegen** was used, not an API/CLI fallback. The v1 original now lives at `public/assets/fleet/harbour workhorse.png`: its bytes matched the former `source/workboat-overhead-v1.png` exactly. The distinct v2 original remains at `source/workboat-overhead-v2.png` (1024 × 1536). v1 has a tilted cabin wall; v2 corrects the camera but has a painted checkerboard background. Both versions remain available for future artwork work.

Generation brief: isolated 10 m × 4 m Canadian Pacific Northwest commercial urchin dive workboat; camera exactly vertical, bow up; weathered aluminum hull and off-white forward cabin roof; broad empty nonslip aft deck for independent game cargo; cleats, rails and fenders; restrained naturalistic materials under diffuse overcast light. No people, bags, water, wake, scene, logo or text; transparent background requested.

Corrective edit: remove the background/halo and replace with zero alpha; eliminate visible vertical cabin and transom wall faces; preserve only the overhead roof, horizontal deck, full centered bow-up silhouette and surface detail. The transparency request was not satisfied by the tool, so a native game mask supplies it. Both generations were visually inspected; the composited sprite was then inspected in the running game and boatyard.

## Procedural materials

`src/coastal-art.js` generates cold water variation, rocky intertidal material, overhead vegetation texture/crowns, fractured stones and current-aligned kelp fronds. Fixed geometry, tide and local current determine where/how these appear. `src/ocean-view.js` preserves the historical wake and adds drive-specific wash, timber and independent cargo/crew overlays.

`assets/source/` retains unique source material. `public/assets/` contains canonical artwork as well as prepared runtime derivatives; do not treat it as a disposable build directory. `dist/` and cached runtime textures are reproducible. Additive playable exports remain the release workflow. No satellite dataset or third-party art licence was introduced.

## Original title and library artwork

`public/assets/brand/` contains original vector artwork and reproducible PNG exports for the title, library capsule/header/hero and transparent logo. Source recipe: `scripts/brand-art.js`; render through `PLAYWRIGHT_BROWSERS_PATH=.browser-cache node scripts/browser-smoke.js --art-only` (also regenerated by the career browser harness). No existing source artwork is overwritten. Format/layout reference: [Valve library assets](https://partner.steamgames.com/doc/store/assets/libraryassets), checked 2026-09-11. The hero contains no lettering; the title/logotype is separate. These are local assets ready for shortcut/library setup.

## Illustrated harbour and Frank — second video iteration

Built-in **imagegen** generated new originals; the existing title image was a palette/style reference only. Unaltered authoring originals are [harbour-v1.png](../public/assets/harbour/harbour-v1.png) (1672×941) and [frank-v1.png](../public/assets/harbour/frank-v1.png) (1254×1254). The game uses these same files. `src/harbour-view.js`, `src/harbour.css` and the optional lesson consume these assets. No image API/CLI fallback or external stock image was used. The duplicate source paths were consolidated after byte-for-byte verification; the original artwork survives in the canonical files.

Harbour prompt: original quiet British Columbia commercial urchin dock, wide illustrated scene in the title's teal/green/cream/ochre palette; office and clipboard official to the left, divers in the middle, practical working boats/fuel shed to the right, older bearded Frank on the wharf; forested mountains, soft dawn light, readable silhouettes and subtle texture. Leave upper sky/lower dock space for real interface controls. No lettering, UI, logos or copied characters.

Frank prompt: original older working fisherman, large white beard, cap, wool sweater, ochre work bibs and coiled rope; chest-up square portrait, kind weathered expression, British Columbia wharf atmosphere, teal/green/cream/amber palette. No existing fictional character, lettering or logos.

The game keeps accessible HTML buttons separate from the artwork. Generated images do not define collisions, stock or game state. Runtime inspection covered the wharf at 1280×800 and 1024×640, crew/boatyard panels, and Frank's lesson; controller selection follows the actual buttons.
