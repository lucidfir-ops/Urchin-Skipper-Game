# September 20 — landscape device feedback

> Historical amendment/implementation record. The current approved design is consolidated in [bible.md](../bible.md). This record preserves provenance; it is not an independent authority or fallback specification.

Authority: the designer's September 20 message and all 20 supplied images under `feedback/9-20/`. These explicit amendments supersede conflicting earlier feedback; the root DOCX remains the definitive design. Baseline is the 14-inch tablet, with landscape S22 and 1280×800 Deck/controller checks. No portrait game layout is developed; touch portrait asks the player to rotate and pauses simulation.

## Decisions and implementation

- Crew portraits are constrained independently of source image resolution. Weather uses the viewport with two forecast columns, a scrollable report and fixed navigation/actions. Fleet reports fill the available width. Arrange UI uses a bounded preview and independently scrollable actions/elements.
- The supplied `doogee e3 tab max 14inch/another empty space to fill.jpg` is appended to DOCX §23 as the current Settings reference. No weather screenshot is added. Original document and every previous ZIP part except document XML and its relationships are preserved; the approved harbour image and existing text are unchanged. [Verification and original](history/2026-09-20-device-feedback/bible-amendment-verification.json); historical recipe: [archived, retired DOCX editing script](../archive/design/2026-09-23/add-settings-reference.py.txt) (originally refused duplicate amendments; do not run against the archive).
- New Career exists only at Title. Logbook offers Save game now and Load saved day / career. Each newly reached planning day gets an immutable starting snapshot; manual Save keeps an additional restore point. Loading first archives current progress. Existing careers and archives stay intact. Earlier days from previous releases cannot be reconstructed. Browser-local snapshots stop growing before consuming the live-save reserve, with a warning to export; unique old snapshots are never pruned automatically. These remain localStorage saves, so clearing browser data can erase them.
- Insurance is automatic on departure. Removed reminder/arming interaction, retained premium costs, injury-adjusted premiums and established coverage/settlement rules.
- Back/B closes Pause to the same water session. Sea Settings → Back resumes the water; Settings children return to Settings first. Harbour Settings returns to Harbour. Other child windows retain their visited parent; only the Harbour/root briefing/starter return path goes to Title. Explicit Return to Title/Exit actions remain explicit.
- Fullscreen moved out of the floating touch toolbar into Title, Settings and Pause, including tutorial pause. Available independent of touch mode. Browser gesture/iframe permission restrictions still apply; the supported itch configuration permits fullscreen/gamepad. No global Deck or Steam shortcuts are changed.
- The touch toolbar is at the top right, clear of rudder controls. “Adjust UI” replaces Lock screen and defaults OFF on launch. It reveals existing move/resize/close handles; separate Hide UI remains. Chart/orders open on touch release, avoiding a held input followed by an immediate close.
- Designer layouts guide adaptive defaults: tablet/phone map upper left and instrument row, bottom diver/boat strips; Deck boat/divers left, instrument row above, gauges right and map bottom right. Existing saved layouts take precedence. Reset all positions/sizes adopts new defaults. Controls help defaults ON for tutorials and OFF for real careers; a deliberate tutorial override is preserved.
- Arrange UI does not drag cards. Select a card, then use move/resize arrows; held touch buttons, keyboard arrows and D-pad repeat. Boat/diver cards can occupy the final bottom strip. The dialog heading can move the bounded dialog without stranding its controls. Save applies; Back discards. Tapping non-control card space (or the minimap image) toggles 25% opacity; tap again restores it. Arrange UI also offers opacity per element. Minimap ↗ / Chart opens the larger map. Raster/Vector buttons are in the controller focus graph.
- Graphic instruments default on: red digital ship's clock, independent depth sounder instrument, speed/fuel dials, throttle/rudder tracks, compass/current, weather meter, hull/deck gauges and diver meters. Data widgets have Graphic/Plain text choices in Arrange UI. Written instructions/alerts remain readable rather than replacing their meaning with icons. The original clock/offload and sounder text cards remain separate switches (off by default in new presets); both/either/neither are supported. Three decorative timepieces are purchasable under Chandlery → Timepiece, selected on purchase and switchable among owned faces in the layout editor. Prices $120/$280/$400 are reversible prototype tuning, not a gameplay bonus.
- Experimental Fit everything to screen is OFF by default. It scales UI text relative to a 1280×800 baseline and fits the intact approved harbour composition; manual UI Scale still adjusts it. On a short phone this necessarily makes harbour labels smaller. Responsive panel bounds and adaptive HUD positions work without enabling the experiment.
- Tutorial terrain is now finite islands surrounded by water on every boundary, including an open southern passage. Lesson progression and aboard checks still gate the taught south-edge return; there is no enclosing land rim or drawn border. Existing tutorial stock/lesson state survives loading. Render-only departure uses the actual approach heading instead of snapping motion to the exit's compass bearing; fading and once-only settlement remain.
- Safe submerged rocks retain blue tones. Shallow hazards have warm crowns and amber broken wash; exposed rocks have a dry bright crown and continuous white rim. Depth/collision bands are unchanged.
- After world-replacing title/menu/tutorial actions, UI rendering refreshes its world reference. This repairs the stale-world path that could blank Frank or fail a training transition; it does not prove every possible physical-device crash is resolved. Optional title-screen troubleshooting records a bounded ring of menu/state/control changes, errors and graphics-context loss, flushes every five seconds/on errors, survives reload and downloads plain text. It is OFF by default, sends nothing, includes no save contents and cannot capture an OS kill or guarantee the final seconds before a crash.

## Rendering and storage

Water animation cache keys had continuously changing environmental floats, often invalidating the intended 15 Hz reuse. Quantized presentation inputs restore reuse. At wide zoom, animated kelp is redrawn into one bounded 1280-pixel texture at 4 Hz instead of hundreds of paths every frame; near views retain full detail. Bed/patch associations are built once instead of searched for each draw. Gauge needles are visually quantized and unchanged default HUD positions avoid repeated layout writes. Simulation geometry, kelp/stock, weather/current, encounters and orthographic camera remain unchanged.

[Full workspace inventory](history/2026-09-20-device-feedback/storage-audit.json): removed only approximately 440 MiB of npm/pip download caches; they can be downloaded again. Preserved browser profiles, careers, downloaded speech models, dependencies, original feedback/art/documents, all historical exports and the DOCX harbour reference. Files outside `dist/` are not shipped to a player, so workspace size was not the tablet frame-rate cause.
