# Minimap, sounder and layout editor — September 17 designer amendment

> Historical amendment/implementation record. The current approved design is consolidated in [bible.md](../bible.md). This record preserves provenance; it is not an independent authority or fallback specification.

The designer requested independent modular minimap/sounder switches, charts as a minimap, charted subtle underwater hazards with conspicuous uncharted hazards, tutorial chart guidance, touch-only live editing handles, and a keyboard/gamepad menu route for arranging all UI. This extends the [shore hazard](FEEDBACK_SHORE_HAZARDS.md) and [UI windows](FEEDBACK_S22_LATEST.md) amendments. It is compatible with the definitive DOCX: the sounder remains strictly local, charts remain a partial survey, and hidden ground/diver information is protected.

The current-sector minimap shares the existing chart painter, charted-rock subset, permitted known-ground markings, saved chart tracks and player marks. It has a live boat triangle and opens the larger chart, including Frank’s lesson chart. It never plots moving logs, uncharted rocks, unknown grounds or underwater divers. Terrain painting is cached; tide, ground state, chart settings and world changes invalidate it. The existing physical uncharted-rock crown/wash contrast is retained. Frank’s safe starter cove retains its intentionally empty collision-rock set, and its charts likewise omit generated rocks that are absent from that cove.

The separate sounder reads the same local tide-adjusted rock-top depth as collision/grounding and reports clearance below the keel. It works with the helm or minimap hidden. Both switches are UI preferences available on any career difficulty, default on in Easy/Realistic and off in All Off. Legacy per-window preferences are preserved and Custom restores the selected set.

Arrange UI layout is available from the sailing menu, Settings and UI options, including during the tutorial. The paused viewport preview includes hidden and conditional information windows. Select a window, choose Move or Resize, and use arrow keys, D-pad or left stick; Confirm/Back ends adjustment. Mouse/touch can drag previews; adjustment modes also offer tappable direction and Finish buttons. Show/hide, individual/all geometry reset, Save and Back/discard are available. Only Save applies the draft. Existing realistic difficulty restrictions still apply to assistance toggles. Prototype window toggles remain session-only; career choices use the existing save/preset system.

Positions **and sizes** now persist in the existing browser layout store, separately for desktop/touch and landscape/portrait, preserving old position-only records. Bounds retain touch bottom clearance. Live corner/move/close controls appear only in explicitly enabled Touchscreen mode; applying saved desktop layouts remains independent of handle visibility. No raw controller mappings or host shortcuts change. A preview represents the viewport in which editing began; rotate before opening the editor to arrange the other orientation.

Tutorial step 4 and the full cove chart explain partial chart surveys, pink rock crosses, visible unmarked crowns/wash, opening the minimap, the local sounder and customization routes. The existing requirement to actually open the chart remains.

Verification: `npm run verify -- --unit-only`, Chromium/Firefox `--browsers-only --suite=minimap-layout` / `--suite=minimap-layout-firefox`, and the touchscreen window smoke flow. See [acceptance](history/2026-09-17-minimap-layout/acceptance/README.md) for actual results/screenshots. Physical Mac/phone/controller and itch.io publication remain follow-up checks.
