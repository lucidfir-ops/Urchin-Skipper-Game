# Current build controls

September 14 implementation of Bible section 19, amended by the designer's R3/difficulty request. The table describes browser-standard Xbox / Steam Input defaults. Existing saved bindings are retained; Controls shows the active device's actual mappings. Optional new shortcuts yield to explicitly assigned actions.

| Control | Action |
| --- | --- |
| Left stick up/down | Increase/decrease persistent throttle |
| Right stick left/right | Increase port/starboard persistent rudder |
| Left stick left/right | Hold fitted bow thruster; cannot simultaneously change throttle |
| Right stick up/down | Twin-jet neutral pivot: up port, down starboard (keyboard Q / E or Up / Down arrows); menu detail scrolling |
| D-pad up/down | Full ahead / full reverse |
| D-pad left/right | Neutral |
| X | Recover bag / send surfaced diver down with a fresh bag |
| Y | Deploy from deck / bring diver and any outstanding bag aboard |
| A while fishing | Clang hull within 5 m of underwater bubbles; diver responds after 2–5 s |
| LB | Select next diver |
| RB | Easy career: Easy → Realistic → All Off; Realistic career: Realistic ↔ All Off. Prototype Lab: test reveal. |
| B | Diver orders |
| R3 | Difficulty / assists |
| L3 | Chart tools |
| LT / RT | Zoom; forecast scrub; search-limit selection in orders |
| Menu | Pause / close menu |
| A / B in menus | Select / Back |
| View | Input diagnostics |

## Keyboard

The [September 15 keyboard amendment](FEEDBACK_KEYBOARD_CONTROLS.md) sets these defaults. Existing custom bindings remain; Controls shows the current map.

| Key | Action |
| --- | --- |
| Tab | Cycle diver |
| W / S | Increase / decrease throttle |
| X or Space | Neutral throttle |
| A / D | Rudder left / right |
| Q / E or Up / Down arrows | Twin-jet spin left / right in neutral |
| Caps Lock or Left arrow | Hold bow thruster left |
| F or Right arrow | Hold bow thruster right |
| 1 | Deploy diver / pick up diver and bag |
| 2 | Pick up bag only / give fresh bag |
| 3 | Clang hull / nearby diver recall |
| Escape | Open menu; close menus to water or harbour |
| + / − (including numeric pad) | Zoom in / out |
| Shift alone | Cycle detail levels; prototype reveal in Prototype Lab |
| Enter | Neutral steering at sea; select in menus |
| Arrow keys in menus | Navigate / point compass orders |
| Backspace / B in menus | Back / cancel |
| B / O at sea | Diver orders |
| Page Up / Page Down | Full ahead / full reverse |
| M / T / G | Chart / tides / prototype boatyard |
| F2 / F3 / F4 / F6 | Remapping / detail levels / diagnostics / assists |

Controls shows one selected Keyboard, Controller or Steam Deck diagram beside its per-action dropdowns and physical capture. Left/right switches view; Up/down selects a row. Reset applies only to the selected device. Select a row using A, release controls, then press the desired input. Controller setup → Verify physical X/Y records the actual buttons and their actions together. Raw Deck axis/button layouts are not assumed; Steam Gamepad emulation or explicit physical mapping is required. Original authoring documents are preserved as historical records.

Touchscreen mode now adds two touch sticks and large action buttons, toggled on the title, Pause and Settings. The same abstract commands preserve controller behavior. Enter / the touch Centre rudder button centres steering. See [touch controls and lifetime handling](FEEDBACK_TOUCH_AND_DIVING.md#touchscreen-and-browser-access).

September 15: [input amendment and acceptance](FEEDBACK_SEPTEMBER15.md). Default pivot bindings yield to confirmed custom mappings; raw devices require explicit mapping.
